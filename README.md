# <u>Todo List Web App (Mini Project)</u>

This is a Mini Project developed using HTML, CSS, and JavaScript.  
The application allows users to add tasks to a list and delete them when completed. It demonstrates the use of DOM manipulation, event handling, event bubbling, event delegation and basic web development concepts.

## <u>🎯 Project Objective</u>

The objective of this mini project is to understand:

- Basic web development structure  
- DOM manipulation using JavaScript  
- Event handling  
- Creating and modifying HTML elements dynamically  

## <u>🚀 Features</u>

- Add new tasks to the list  
- Delete tasks from the list  
- Simple and user-friendly interface  
- Dynamic task management using JavaScript

## <u>🛠️ Technologies Used</u>

- **HTML5** – For creating the structure of the webpage  
- **CSS3** – For styling and layout  
- **JavaScript (Vanilla JS)** – For adding functionality and interactivity
